Documentation

Krux, assistant IA pour Android

Discuter

Krux analyse la question, puis vérifie sa réponse avant de l'envoyer. La ligne « Réflexion » en haut du message indique le temps passé. Il peut chercher sur le web quand la question en a besoin.

  • Plusieurs modèles d'IA, au choix.
  • Appui long sur une réponse : copier, tout sélectionner.
  • Les liens s'affichent en boutons et s'ouvrent dans le navigateur intégré.
  • Photos : jusqu'à deux images par message, avec rotation et rognage.

Parler

Krux lit ses réponses à voix haute, avec pause et reprise.

Fichiers et export

Tout fichier généré par Krux est rangé dans l'onglet Fichiers. Une discussion peut être exportée en PDF ou en CSV.

Créer des applications

Demande une application à Krux. Elle apparaît dans « Mes apps », avec son code source en archive.

Krux Code

Krux Code propose des modifications de code sous forme de différences : lignes retirées en rouge, lignes ajoutées en vert. Rien n'est modifié avant « Appliquer ». « Annuler » laisse le code intact.

Compte

Ton compte te permet de retrouver tes discussions sur un autre téléphone.

Apparence

Thèmes clair et sombre, appliqués à toute l'application.
