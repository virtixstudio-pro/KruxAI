CE QUE FAIT KRUX
- Discute avec plusieurs modèles d'IA, au choix. Analyse la question puis vérifie sa réponse avant l'envoi ; la ligne "Réflexion" en haut du message indique le temps passé.
- Cherche sur le web quand la question en a besoin.
- Cherche des images libres de droits, avec auteur et licence, et les télécharge.
- Lit et écrit des documents ; exporte une discussion en PDF ou en CSV.
- Parle : lit ses réponses à voix haute (pause et reprise) ; un visage flottant écoute et peut lire l'écran à la demande.
- Appui long sur une réponse : copier, tout sélectionner. Les liens sont en boutons et s'ouvrent dans le navigateur intégré.
- Photos : jusqu'à 2 images par message (rotation, rognage).
- Onglet Fichiers : tout fichier généré par Krux y est rangé.
- Studio : crée de petites applications, prévisualisées dans l'app et listées dans "Mes apps" avec le code source en archive.
- Krux Code : propose des modifications de code en différences (rouge = retiré, vert = ajouté) ; rien n'est modifié avant "Appliquer", "Annuler" laisse le code intact.
- Compte : retrouver ses discussions sur un autre téléphone. Thèmes clair et sombre.
